## Overview

LIVEARf uses a **usage-based pricing model**. Your monthly cost is calculated based on the features and tools you have active — you only pay for what you use. There are two payment options: **Monthly** and **One-time**.

---

## Monthly vs One-time Pricing

<Tabs>

  <Tab title="Monthly Pricing">

    ### Plan Summary

    Your monthly cost is broken into three sections:

    ![Plan Summary — showing Design Types, Visualization, Features & Tools breakdown and total](/images/pricing/pricing-monthly.png)

    **Design Types** — charged per product:

    | Feature | Price |
    |---|---|
    | Standard Frame | $5.00 |
    | 1st / Top Mat (Size, Style, Colour) | $5.00 |
    | **Design Types Total** | **$10.00** |

    **Visualization** — added on top of Design Types:

    | Feature | Price |
    |---|---|
    | 2D Visualization | $1.10 |
    | **Total with Visualization** ($10.00 × $1.10) | **$11.00** |

    **Features & Tools** — charged per product for each active feature:

    | Category | Feature | Price |
    |---|---|---|
    | **Image Upload** | Image Storage (GCS Bucket) | $5.00 |
    | | Orientation Portrait Landscape | $2.00 |
    | | Image Cropper | $2.00 |
    | | Image Quality Indicator | $2.00 |
    | | Custom Size Image Cropper | $2.00 |
    | **Room View** | Size Based Room Change | $3.00 |
    | | Enlarge View | $2.00 |
    | **Frame Generator** | 2D Frame Generator (Product Page) | $5.00 |
    | **System Constraints** | More than 3 Components | $5.00 |
    | | More than 5 Options Per Component | $3.00 |
    | | More than 10 Rules Per Component | $3.00 |
    | **Features & Tools Total** | | **$34.00** |

    **Pricing Summary:**

    | | Amount |
    |---|---|
    | Design Types & Visualization | $11.00 |
    | Features & Tools | $34.00 |
    | Product Price (up to 1000) | $1.80 |
    | **Total Price** ($11.00 + $34.00) × $1.80 | **$81.00 / month** |

    <Info>
      Your plan total updates automatically as you add or remove features and components. Click **Update Plan** at the bottom to apply any changes, then click **Pay** to confirm.
    </Info>

  </Tab>

  <Tab title="One-time Pricing">

    ### Service Pricing

    For one-time payments — such as custom setup, professional services, or invoice-based billing — use the **One-time Pricing** tab.

    ![Service Pricing — Invoice Number field, Amount field in USD, and Pay button](/images/pricing/pricing-onetime.png)

    1. Enter your **Invoice Number** provided by the LIVEARf team
    2. Enter the **Amount** in USD
    3. Click **Pay** to complete the payment

    <Info>
      One-time pricing is used for service invoices issued by LIVEARf. If you have not received an invoice number, contact **cs@livearf.com** before proceeding.
    </Info>

  </Tab>

</Tabs>
