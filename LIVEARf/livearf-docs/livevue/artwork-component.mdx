## What is the Artwork Component?

The Artwork Component is designed for **artists and photographers** who sell ready-made artwork and want to offer customers interactive customization — including size selection, frame styles, and mat options — with a live preview that updates in real time.

<Info>
  The Artwork Component works with your existing artwork images. Customers cannot upload their own images here. For customer uploads, see the [Upload Component](/livevue/upload-component).
</Info>

![Customer-facing artwork product page showing live size, frame, and mat selection](/images/artwork/product-preview.png)

---

## Accessing the Artwork Component

1. Open the **LIVEARf app** from your Shopify admin
2. Navigate to **Components** in the left-hand menu
3. Select an existing **Artwork Component** or click **Create My Own**
4. Open the **Basic Configuration** tab

![LIVEARf app dashboard showing the Components menu and Create Components button](/images/artwork/dashboard.png)

You will see two panels side by side:
- **Left panel** — your configuration settings
- **Right panel** — a live **Preview Product** that updates as you make changes

---

## Component Header Settings

At the top of the configuration screen, three key settings control the component's basic behaviour.

![Component header showing Component Name field, Image Upload toggle, Quick Setup Guide button, and Component Status toggle](/images/artwork/component-header.png)

<ParamField path="Component Name" type="string" required>
  An internal label used to identify this component. This name is not shown to customers on your storefront.
</ParamField>

<ParamField path="Image Upload" type="toggle">
  Enables or disables image upload on the product page. For the Artwork Component this is typically **disabled**, since your artwork images are pre-defined.
</ParamField>

<ParamField path="Component Status" type="toggle" required>
  Turn **ON** to activate the component and make it available to link to products. Turn **OFF** to temporarily disable it without deleting it.
</ParamField>

<Warning>
  Always click **Save** after making any changes. Unsaved changes are lost if you navigate away.
</Warning>

## Options Panel

The Options panel controls every customization choice your customers will see on the product page.

![Options panel listing Shopify Options 1–3 alongside custom Frames, Mat Size, and Mat Colour options](/images/artwork/options-list.png)

### Shopify Options (inherited)

The first three options are automatically pulled in from your Shopify product variants. These represent your existing Shopify product options (e.g. Size).

- Use the **eye icon** to show or hide each option on the storefront
- Hidden options will not appear in the live Preview Product panel

### Custom Options (LIVEARf)

LIVEARf adds three custom options by default:

| Option | Purpose |
|---|---|
| **Frames** | Frame style selection with visual swatches |
| **Mat Size** | Controls the spacing between the artwork and the frame |
| **Mat Colour** | Controls the colour of the mat border |

Each custom option can be **edited**, **duplicated**, or **deleted** at any time.

## Configuring an Option

Every option — whether Shopify-inherited or custom — follows the same configuration steps.

<Steps>

  <Step title="Select the option">
    Click on the option name (e.g. **Frames**) from the options list on the left.
  </Step>

  <Step title="Define option details">
    | Field | Description |
    |---|---|
    | **Option Name** | Internal reference only — not shown to customers |
    | **Option Label** | The label displayed to customers on the product page |
    | **Hide Option** | Toggle to control visibility on the storefront |

    ![Option Name (internal, red box) versus Option Label (customer-facing, green box) for the Frames option](/images/artwork/option-name-label.png)
  </Step>

  <Step title="Choose an option type">
    Select how customers will interact with this option:

    | Type | Best used for |
    |---|---|
    | **Swatch** | Frame images or mat colour thumbnails |
    | **Rectangle** | Size options (e.g. 10×10, 20×20) |
    | **Radio Button** | Single-choice text selections |
    | **Dropdown** | Long lists of choices |
    | **Number** | Custom size inputs |
    | **Colour** | Colour picker for mat colours |

    ![Option type dropdown open showing all six available types: Swatch, Rectangle, Radio Button, Number, Colour, Dropdown](/images/artwork/option-type-dropdown.png)

    The Preview Product updates instantly when you change the option type.
  </Step>

  <Step title="Assign a Section">
    The Section determines how the option behaves visually on the product page.

    | Section | Purpose |
    |---|---|
    | **Frame** | Frame visualization and styles |
    | **Mat** | Mat appearance (visual only) |
    | **Canvas** | Canvas wrap rendering styles |
    | **Acrylic** | Acrylic mounting styles |
    | **Metal** | Metal print styles |
    | **Wood** | Wood-based finishes |
    | **Custom Size** | Custom width and height input |
    | **Custom Mat Size** | Custom mat spacing |
    | **Pricing** | Pricing adjustments |
    | **Additional** | Optional add-ons |
    | **None** | No special behaviour |

    ![Section dropdown open showing all available section types including Frame, Mat, Canvas, Acrylic, Metal, Wood, Additional, Pricing, Units, None](/images/artwork/section-dropdown.png)

    **Section = Frame** — unlocks frame thumbnail columns (Main + Thumb) in the option values panel:

    ![Section set to Frame, showing option values Gold, White, Black, Wood with Main and Thumb image columns](/images/artwork/section-frame.png)

    **Section = Mat** — shows an Image swatch column for each mat value:

    ![Section set to Mat, showing option values with the Image column for uploading mat colour swatches](/images/artwork/section-mat.png)
  </Step>

  <Step title="Configure option values">
    Option values are the individual choices available to customers (e.g. Gold, White, Wood, Black for Frames).

    For each value you can:
    - Set a **label** (shown to customers)
    - Upload or select a **thumbnail image**
    - Mark one value as the **default selection**
    - **Duplicate** or **delete** the value

    All values appear visually in the Preview Product panel on the right.
  </Step>

</Steps>

## Actions (Section-Specific)

Some sections unlock an **Action** dropdown for each option value, giving you control over how that value renders visually.

![Action dropdown for the Frame section showing Standard Frame, Infinity Frame, and Floater Frame options](/images/artwork/action-dropdown.png)

| Section | Available Actions |
|---|---|
| **Frame** | Standard Frame, Infinity Frame, Floater Frame |
| **Canvas** | Classic Wrap, Mirror, Colour, Blur |
| **Acrylic** | Spacers, Mount, Sandwich |
| **Metal** | Print, Float Mount |
| **Wood** | Wooden Pallet, Box Board |
| **Pricing** | Discount, Margin, Markup |

<Note>
  If a section does not support actions (such as **Mat**), the Action dropdown is greyed out and disabled automatically.
</Note>

## Mat Size Configuration

The Mat Size option controls the spacing between the artwork edge and the inner frame edge. It supports both **single mat** and **double mat** configurations.

![Mat Size option showing Option Name = Mat Size, Section = Mat, Action = First Mat Size, with values 2 inch, 1 inch, No Mat](/images/artwork/mat-size-config.png)

Each mat level has three sub-settings:

| Sub-option | Purpose |
|---|---|
| **Mat Size** | The width of the mat border |
| **Mat Style** | The visual style applied |
| **Mat Colour** | The colour of the mat |

![Mat Action dropdown showing First Mat Size, First Mat Style, First Mat Colour, Second Mat Size, Second Mat Style, Second Mat Colour](/images/artwork/mat-size-actions.png)

This applies independently to both the **First Mat** and **Second Mat** layers.

Mat Size supports all pricing methods. Use the **edit icon** on the right of each value to configure pricing for that specific mat size.

---

## Mat Colour Configuration

The Mat Colour option controls the visual colour of the mat layer. It shares the same six mat action types as Mat Size and supports all pricing methods.

![Mat Colour option showing Option Name = Mat Colour, Section = Mat, Action = First Mat Style, with Black and White swatch values](/images/artwork/mat-colour-config.png)

Use the **image icon** on each value to visually select or upload mat colour swatches. Changes are reflected immediately in the Preview Product panel.

---

## Pricing Configuration

Each option value can have a price applied to it. LIVEVUE supports four pricing methods:

| Method | How it works |
|---|---|
| **Fixed Price** | A flat amount added regardless of size |
| **Predefined Price** | A specific price per defined value (e.g. per size variant) |
| **Surface Area** | Price calculated based on width × depth |
| **Perimeter** | Price calculated based on the edge measurement |

![Price Type dropdown showing all available pricing methods: Fixed Price, Surface Area, and Predefined Pricing variants](/images/artwork/pricing-config.png)

![Fixed Price (Standard) selected as the Price Type, with the pricing edit icon highlighted on an option value row](/images/artwork/standard-pricing.png)

All pricing methods support a **Tooltip** (short explanation shown on hover) and a **Description** (longer explanation). Use the **(i) icon** for a visual measurement guide.

## Advanced Configuration — Conditional Rules

Conditional rules let you dynamically show, hide, or disable options based on what a customer has already selected. This keeps the product page clean and relevant.

### How rules work

Each rule follows simple **IF → THEN** logic:

- **WHEN** — the option that triggers the rule (e.g. Frames)
- **IS** — the condition (Equals to, Not equals to, Greater than, Less than)
- **THEN** — the action to take (Show, Hide, or StrikeOut) on a target option

### Setting up a rule

1. Open the **Advanced Configuration** tab
2. Expand the **Conditional Rules** section
3. Click **Add New Rule**
4. Configure the WHEN / IS / THEN fields
5. Click **Sync** to apply

![Conditional Rules panel showing When / is / then dropdown fields, operator selector, and Add New Rule button](/images/artwork/conditional-rules.png)

### Example rules

<AccordionGroup>
  <Accordion title="Hide Mat Colour when Black frame is selected">
    **When** Frames **equals** Black → **Hide** Mat Colour
  </Accordion>
  <Accordion title="Show specific frames when mat size is 2 inch">
    **When** Mat Size **equals** 2 inch → **Show** Frames (Gold, White)
  </Accordion>
  <Accordion title="StrikeOut Black frame when Wood is selected">
    **When** Frames **equals** Wood → **StrikeOut** Black Frame
  </Accordion>
</AccordionGroup>

<Tip>
  Rules are applied in the order they are listed. You can duplicate rules for reuse and add multiple conditions using operators. Always click **Sync** after updating rules, then test in the Preview Product panel.
</Tip>

## Preview & Saving

Before saving your component, use the **Preview Product** panel on the right to:

- Test different combinations of size, frame, and mat
- Verify pricing is calculating correctly
- Confirm conditional rules are triggering as expected

![Preview Product panel highlighted on the right side of the component editor, showing live frame and size selection](/images/artwork/preview-validation.png)

When everything looks correct, click **Save** in the top-right corner.

---

## Linking the Component to Products

Once saved, the component must be linked to products before customers can see it.

<Steps>
  <Step title="Enable the component">
    Make sure **Component Status** is turned **ON** and all changes are saved. The **Link** button only appears after the component is enabled.
  </Step>
  <Step title="Open the Link panel">
    Click **Link** in the top-right corner of the component configuration screen.
  </Step>
  <Step title="Choose how to apply it">
    | Option | What it does |
    |---|---|
    | **Selected Collections** | Applies to all products within chosen Shopify collections |
    | **Selected Products** | Applies only to individually chosen products |
    | **All Products (LIVEVUE Template Enabled)** | Applies to every product already using a LIVEVUE template |

    Click **Link** to confirm.
  </Step>
  <Step title="Verify the link">
    Go to **LIVEARf → Components**. You will see the component listed with the number of linked products and a status of **Active**.
  </Step>
</Steps>
